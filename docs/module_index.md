# Module Index

`mintcdr.data`  
CSV/JSON loading, sequence construction, negative sampling, target-domain ground truth.

`mintcdr.model`  
The main MINTCDR model: sequence encoder, ID branches, DICN, utility head.

`mintcdr.trainer`  
Training loop, validation, checkpoint saving, utility distillation.

`mintcdr.baselines`  
Target-only MF and dual-domain MF.

`mintcdr.metrics`  
Recall and NDCG.

`mintcdr.prompts`  
Small helpers for rendering semantic-feature prompts.
